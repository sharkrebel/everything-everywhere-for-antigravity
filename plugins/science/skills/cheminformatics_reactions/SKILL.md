# RDKit Chemical Reactions & Mechanism Arrows (`cheminformatics-reactions`)

## Prerequisites

1.  **`rdkit-general`**: Read the `rdkit-general` skill before running any
    workflow here.
2.  **`uv`**: Read the `uv` skill and follow its Setup instructions to ensure
    `uv` is installed and on PATH. Always execute skill scripts as `uv run
    /path/to/script.py ...` (or `python3 /path/to/script.py ...`); **never** run
    `uv run python3 /path/to/script.py`, as placing `python3` after `uv run`
    bypasses the script's PEP 723 `# /// script` dependency block.
3.  **User Notification**: If `.licenses/cheminformatics_reactions_LICENSE.txt`
    does not already exist in the workspace root then (1) prominently notify the
    user of the terms of use for the tools and data sources this skill relies
    on, then (2) create the file recording the notification text and timestamp:
    -   **RDKit**: BSD 3-Clause License (Landrum et al.)
    -   **Open Reaction Database (ORD)** (CC BY-SA 4.0,
        https://open-reaction-database.org), **PubChem PUG REST**, and **Google
        Patents** (https://patents.google.com), when running
        `../cheminformatics_doc2mol/scripts/precedent_lookup.py`

## Core Rules

-   **Shared foundation rules**: Follow all core rules in
    `../rdkit_general/SKILL.md`.
-   **Precedent-first reaction & synthesis design**: Before proposing a
    reaction, conditions, or synthesis route, unless prompted otherwise by the
    user, search ORD/USPTO and Google Patents via
    `uv run ../cheminformatics_doc2mol/scripts/precedent_lookup.py --api all`
    (`--product "<TARGET_SMILES>"`, `--reaction-smiles "R_SMILES>>P_SMILES"`, or
    `--batch-json <steps.json>`) plus peer-reviewed literature
    (`pubmed-database`, `literature-search-openalex`). Adopt or adapt attested
    routes and conditions (citing ORD IDs, patent numbers, or DOIs/PMIDs);
    design de novo steps only when no viable precedent exists and explicitly
    label them as proposed extensions.
-   **Electron-pushing arrows on every transformation**: Any reaction,
    intramolecular cyclization, or synthesis step you propose or depict must be
    delivered as a 2D diagram with curved electron-pushing arrows (rendered in
    Crimson `#E11D48`), generated by `scripts/render_mechanism.py`. Never
    substitute a straight arrow or a static precursor/product compound grid for
    a transformation.
-   **Decompose cofactor- or catalyst-mediated reactions into elementary
    steps**: When an enzymatic or catalytic transformation involves a cofactor
    or catalyst, never depict the composite net reaction as a single concerted
    step without the cofactor or catalyst. Always include the explicit cofactor
    or catalyst SMILES (with `atom_labels` for abbreviated prosthetic groups,
    ligands, or residues as needed) and step through the elementary catalytic
    sequence (activation, substrate turnover, and resting-state regeneration).

## 1. Geometric, Stereochemical, & Residue Identity Invariants

Read `references/mechanism_arrow_geometry.md` for complete Bézier curve
equations, glyph exclusion radii ($r_{\text{glyph}}$), double-bond normal
clearance ($0.24\text{ cm}$), and amino acid residue SMILES templates.

1.  **Reaction Orientation & Kekulé Consistency (`--auto-rotate` &
    `scripts/rotation_solver.py`)**: Pass `--auto-rotate` on the CLI (or
    `"auto_rotate": true` in JSON/YAML) to automatically solve 12-angle
    ChemDraw/IUPAC orientations for reactants and MCS minimum-RMSD scaffold
    alignment for products. `render_mechanism.py` automatically selects the
    arrow-consistent Kekulé resonance contributor on aromatic reactants,
    preserves post-arrow Kekulé bond orders on aromatic products, and aligns
    product ring scaffolds via 2D $O(2)$ Procrustes over `CompareAny` MCS so
    rings (e.g., $\text{NAD}^+ \leftrightarrow \text{NADH}$) never mirror-flip
    relative to reactants.
2.  **Explicit Hydrogens (`add_h`), Dummy Labels (`atom_labels`), & Amino Acid
    Side-Chain Identity Gate**:
    -   Pass `add_h: {"r1": parent_atom_idx}` whenever an arrow starts or ends
        on a $\text{C}-\text{H}$ or heteroatom $-\text{H}$ bond; omit `"side"`
        on short intramolecular proton transfers so `compute_attack_bezier`
        selects the direct interior arc.
    -   Provide `atom_labels: {atom_idx: "Label"}` for dummy attachments (`*`).
    -   **Amino Acid Side-Chain Identity Gate**:
        `verify_mechanism_with_electron_graph` enforces that any molecule whose
        `name` or `atom_labels` names a canonical amino acid residue uses its
        authentic functional group (e.g. `*c1cnc[nH]1` / `*c1c[nH+]c[nH]1` for
        `His`, `*CC(=O)[O-]` / `*C(=O)[O-]` for `Asp`/`Glu`, `*CS` / `*C[S-]`
        for `Cys`, `*CO` for `Ser`, `*CC[NH3+]` for `Lys`; see
        `references/mechanism_arrow_geometry.md` for all 20 residues).
3.  **Collision-Free Clearances & Exterior Ring Sectors**:
    -   Bond cleavage arrows maintain a $0.24\text{ cm}$ normal offset from
        double bonds ($0.14\text{ cm}$ for single bonds).
    -   Inward curvature toward a ring center is prohibited unless **both**
        bonds belong to that ring; exocyclic shifts stay strictly in the open
        exterior sector.
    -   Inspect the `[AUDIT]` lines printed by `render_mechanism.py` on every
        run; CLI invocations run with `strict_audit=True` and exit non-zero on
        any bond, glyph, or arrow-to-arrow clearance failure.

## 2. Standard Executables & Reference Guides

### Reference Guides (`references/`)

-   `references/mechanism_json_recipes.md` — read when authoring JSON/YAML
    mechanism specs, selecting from the 5 arrow types (`attack`, `bond_cleave`,
    `bond_to_bond`, `bond_to_atom`, `lone_pair_to_bond`), 1e fishhooks
    (`"electrons": 1`), multi-step cascades (`"steps": [...]`), circular
    catalytic cycles (`"mode": "catalytic_cycle"`), or calling the
    `compile_clean_reaction` Python API.
-   `references/mechanism_arrow_geometry.md` — read when tuning Bézier arrow
    geometry, `--auto-rotate`, `add_h`, or verifying canonical Amino Acid
    Side-Chain Identity Gate SMILES templates.
-   `references/atom_conservation_and_smarts_verification.md` — read when
    checking reaction stoichiometry (`verify_atom_conservation.py`), authoring
    intramolecular Reaction SMARTS, synthesizing electron-pushing curved arrows
    automatically from atom-mapped SMILES
    (`ReactionVerifierEngine.solve_arrows_from_mapped_smiles`), or running
    `ElectronGraph` (including `strict_lewis=True` dipolar normalization and
    Tier 4 Bredt's rule bridgehead strain checks) and the 6-tier
    `ReactionSMARTSValidator`.
-   `references/reaction_catalog_100.md` — read when looking up any of the 100
    named organic reaction mechanisms and SMILES templates.

### Standard Executables (`scripts/`)

-   `uv run scripts/render_mechanism.py` — Compiles reaction mechanism JSON/YAML
    specifications into 300 DPI PNGs via RDKit + LaTeX/TikZ (`--rxn-json`,
    `--rxn-yaml`, `--out-dir`, `--auto-rotate`).
-   `uv run scripts/reaction_to_cdxml.py` — Generates ACS Document 1996 ChemDraw
    (`.cdxml`) single- and multi-step reaction schemes (`--json`, `--output`).
-   `uv run scripts/verify_atom_conservation.py` — Validates reaction
    stoichiometry, heavy-atom balance ($\Delta C = 0$), and ring count changes
    (`--precursor`, `--product`, `--byproducts "2*H2O"`, `--strict-hydrogen`).
-   `uv run scripts/reaction_smarts.py` — Generates, validates (6-tier), and
    converts Reaction SMARTS (`--smarts`, `--intramolecular`,
    `--make-intramolecular`, `--list-templates`).
-   `uv run scripts/electron_graph.py` — Formal graph-theoretic reaction
    verification and electron-pushing engine: Dugundji–Ugi automated
    curved-arrow synthesis (`solve_arrows_from_mapped_smiles`), strict Lewis
    dipolar normalization (`strict_lewis=True`), and stereochemical checks
    (spectator stereocenter retention, $sp^2$ planarization, $S_N2$
    inversion/retention/racemization, prochiral $sp^2$/$sp^3 \to sp^3$ `Re`/`Si`
    and `R`/`S` stereogenesis, alkene $E/Z$, and Bredt's rule $S = x + y + z <
    7$ bridgehead strain; see
    `references/atom_conservation_and_smarts_verification.md`).
-   `uv run scripts/prochirality.py` — Perceives $sp^3$ (`pro-R`/`pro-S`) and
    $sp^2$ (`Re`/`Si`) prochirality, classifies ligand/face topicity
    (`homotopic`, `enantiotopic`, `diastereotopic`), computes fast-exchange
    stereotopic ${}^{1}\text{H}$ / ${}^{13}\text{C}$ NMR symmetry classes
    (`achiral_classes_by_element`), and validates reaction stereogenesis
    (`--smiles`, `--precursor`, `--product`, `--chiral-catalyst`).
-   `uv run scripts/rotation_solver.py` — Multi-objective reactant orientation
    and MCS product alignment solver.
-   `uv run scripts/eln_reaction_table.py` — Computes stoichiometric electronic
    lab notebook (ELN) reagent tables (equivalents, masses, volumes, limiting
    reagent, theoretical yield).
-   `uv run scripts/build_gallery.py` — Compiles an interactive HTML gallery of
    rendered mechanisms (`scripts/reactions_data.py` and
    `scripts/reaction_specs_100.py` hold the 100-reaction database and arrow
    coordinates).

## 3. Essential JSON & Intramolecular SMARTS Recipes

### A. Minimal Intramolecular Cyclization (`scripts/render_mechanism.py`)

```json
{
  "id": "lactonization",
  "title": "Intramolecular Lactonization",
  "r1": {"smi": "[O-:1]CCC[C:2](=O)[Cl:3]"},
  "p1": {"smi": "O=C1CCCO1"},
  "cond": {"top": "Et3N, THF", "bottom": "-Cl-"},
  "arrows": [
    {"type": "attack", "src": ["r1", ":1"], "tgt": ["r1", ":2"]},
    {"type": "bond_cleave", "mol": "r1", "bond": [":2", ":3"], "tgt": ":3"}
  ]
}
```

```bash
uv run scripts/render_mechanism.py --rxn-json scratch/cyclization.json --out-dir ./images --auto-rotate
```

### B. Intramolecular Reaction SMARTS Parentheses Rule (`scripts/reaction_smarts.py`)

In RDKit Reaction SMARTS, top-level dots (`.`) define separate reactant
molecules (`GetNumReactantTemplates() > 1`). For an **intramolecular ring
closure on a single bifunctional precursor**, disconnected reacting functional
groups **must be grouped inside outer parentheses**:

-   ❌ **Wrong (Intermolecular Dimerization Trap)**:
    `[C:1](=[O:2])[OH].[N;H1:3]>>[C:1](=[O:2])[N:3]`
-   ✅ **Correct (Intramolecular Ring Closure)**:
    `([C:1](=[O:2])[OH].[N;H1:3])>>[C:1](=[O:2])[N:3]`
-   Verify via CLI: `uv run scripts/reaction_smarts.py --smarts "<SMARTS>"
    --intramolecular`

### C. Atom Conservation, NMR Symmetry, & Stereogenesis Validation (`scripts/verify_atom_conservation.py` & `scripts/prochirality.py`)

Always verify $\Delta C = 0$, heavy-atom conservation, fast-exchange stereotopic
${}^{1}\text{H}$ / ${}^{13}\text{C}$ NMR symmetry classes
(`achiral_classes_by_element`, assuming rapid single-bond rotation and a single
diastereomeric state), and stereogenesis validity (rejecting false `@`/`@@`
chirality on homotopic centers and checking `pro-R`/`pro-S` or `Re`/`Si`
prochirality) before finalizing any proposed transformation. Never rely on
`Chem.CanonicalRankAtoms` alone for ${}^{1}\text{H}$ NMR peak counts on cyclic
or chiral molecules, as it fails to split diastereotopic $-\text{CH}_2-$ protons
attached to the same carbon even with 3D coordinates:

```bash
uv run scripts/verify_atom_conservation.py \
    --precursor "<PRECURSOR_SMILES>" --product "<PRODUCT_SMILES>" \
    --reaction-type amide --macrocycle-size 12

uv run scripts/prochirality.py --smiles "<SMILES>"
uv run scripts/prochirality.py --precursor "<PRECURSOR_SMILES>" --product "<PRODUCT_SMILES>"
```
