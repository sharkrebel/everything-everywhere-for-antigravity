# Scientific Reporting, Visualization & Deliverable Synthesis

This guide establishes standards for communicating chemical, computational, and
statistical evidence across modeling workflows using the production engines
`scripts/plot_archetypes.py` and `scripts/report_builder.py`.

--------------------------------------------------------------------------------

## 1. Universal Visualization Invariants

Every graphical deliverable generated by the skill must adhere to these
standards:

1.  **"Every Computed Trend Deserves Visual Context"**: Never leave calculated
    metrics, distributions, or SAR predictions solely as raw CSV text. Always
    render a visual figure.
2.  **Publication-Ready Styling**:
    -   **Resolution**: 300 DPI (`dpi=300`), anti-aliased PNG.
    -   **Layout**: Always use `layout="constrained"` or
        `plt.tight_layout(pad=3.0)` to eliminate label clipping and text
        overlap.
    -   **Units & Explicit Labels**: Every axis must have explicit metric names
        and units (e.g. `Potency pIC50 (-log M)`, `Energy (kcal/mol)`,
        `Molecular Weight (g/mol)`).
    -   **Non-Overlapping Callouts**: Annotate only key anchor molecules
        (leads/benchmarks). Use bounded callouts with leader arrows and
        semi-transparent backgrounds.
    -   **Strict Absolute Paths in Markdown**: Embed figures using absolute
        paths: `![Figure Title](/absolute/path/to/artifacts/figure_name.png)`
3.  **Verbatim Metric Concordance (Zero Discrepancy)**:
    -   Every quantitative statistic quoted in the Markdown report—Executive
        Summary, bullet points, tables, and captions—must be an exact verbatim
        copy of the numbers in the companion CSV and figure stats cards.
    -   Never write narrative numbers from memory or invent idealized
        correlations. If a model correlation is poor, report the exact
        calculated numbers faithfully and explain the mechanistic root cause.
4.  **Multi-Endpoint Visual Completeness**:
    -   Never cherry-pick or plot a single biological endpoint when multiple
        were evaluated. Use grouped bar charts or multi-panel subplots (1 panel
        per target/mutant) to present all targets transparently.

## 2. Production Visualization Engine (`plot_archetypes.py`)

All multi-panel figures should be generated by importing from or invoking
`plot_archetypes.py`. It handles subplot layout, anti-overlap padding, and stats
card placement automatically.

### Key Plotting Functions:

1.  **Multi-Target Parity Grid (`plot_multi_target_parity`)**: Renders $1 \times
    N$ or $2 \times 2$ parity plots with 1:1 diagonal reference lines, separate
    markers for `Train (CV)` and `Holdout Test`, and non-overlapping stats cards
    ($R^2$, Pearson $r$, RMSE, $N$).

    ```python
    from plot_archetypes import plot_multi_target_parity
    plot_multi_target_parity(
        df=predictions_df,
        target_col="Target",
        exp_col="Actual",
        pred_col="Predicted",
        output_png="scratch/multitarget_parity_grid.png",
    )
    ```

2.  **Multi-Representation Benchmark Comparison
    (`plot_representation_benchmark_comparison`)**: Renders grouped bar charts
    comparing Train CV and Holdout Test performance ($R^2$, Pearson $r$) across
    all evaluated representations (2D vs FP vs Physics vs Hybrid).

    ```python
    from plot_archetypes import plot_representation_benchmark_comparison
    plot_representation_benchmark_comparison(
        summary_df=benchmark_df,
        output_png="scratch/representation_comparison.png",
    )
    ```

3.  **Standardized Feature Importance / Coefficients
    (`plot_directional_barh`)**: Draws a ranked horizontal bar chart with
    symmetric auto-padded axis limits and directional label placement, so
    negative bars never collide with the category tick labels. This one is an
    Axes-level helper: it draws onto a figure you own and you save it.

    ```python
    import matplotlib.pyplot as plt
    from plot_archetypes import plot_directional_barh

    fig, ax = plt.subplots(figsize=(7, 5))
    plot_directional_barh(
        ax,
        categories=top_descriptor_names,
        values=standardized_coefficients,
        title="Standardized model coefficients",
        xlabel="Weight",
    )
    fig.savefig("scratch/feature_weights.png", dpi=300, bbox_inches="tight")
    ```

4.  **SAR Matched Molecular Pair Landscape (`plot_mmpa_sar_landscape`)**:
    Renders a two-panel composite: top single-cut transformations ranked by mean
    ΔActivity with standard deviations and pair counts, and a SALI
    activity-cliff scatter (ΔActivity vs Tanimoto similarity) with annotated
    cliff leads.

    ```python
    from plot_archetypes import plot_mmpa_sar_landscape
    plot_mmpa_sar_landscape(
        mmpa_df=transforms_df,
        sali_df=cliffs_df,
        output_png="scratch/mmpa_sar_landscape.png",
        target_label="pIC50",
    )
    ```

## 3. Production Report Generation (`report_builder.py`)

Use `scripts/report_builder.py` to synthesize publication-quality Markdown
deliverables that enforce metric concordance, embedded figures, and structured
execution progression:

```bash
uv run scripts/report_builder.py \
    --benchmark_csv scratch/ml_benchmark_summary.csv \
    --predictions_csv scratch/predictions_cv_and_test.csv \
    --parity_png scratch/multitarget_parity_grid.png \
    --weights_png scratch/feature_weights.png \
    --title "Example Target Series: Machine Learning SAR Report" \
    --output_md "/absolute/path/to/artifacts/sar_modeling_report.md"
```

### Report Section Standards:

1.  **Executive Summary**: Core scientific findings, top performing
    representations, and prospective test generalization.
2.  **SAR & Feature Engineering Progression Table**: Demonstrating baseline vs.
    engineered iterations with $\Delta R^2$ and $\Delta\text{RMSE}$.
3.  **Multi-Target Parity & Goodness-of-Fit**: Embedded high-resolution figure
    with verbatim stats cards.
4.  **Standardized Feature Attributions**: Mechanistic interpretation of top
    positive and negative regression weights.
5.  **Prospective Generalization & Failure Analysis**: Transparent analysis of
    holdout test predictions and outlier residuals.
